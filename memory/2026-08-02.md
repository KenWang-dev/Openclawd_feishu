## Claude Code 动态监控 (09:30 GMT+8)

### 最新版本: v2.1.128

**关键更新：**
- **OS CA证书信任** — 默认信任系统CA证书库，企业TLS代理无需额外配置（`CLAUDE_CODE_CERT_STORE=bundled` 可回退）
- **MCP工具计数** — `/mcp` 现在显示连接服务器的工具数量，零工具服务器会被标记
- **插件zip支持** — `--plugin-dir` 现在支持.zip插件包
- **1M上下文修复** — 修复了1M上下文模型在达到API限制前被误报"Prompt too long"的问题
- **缓存优化** — 子agent进度摘要现在命中prompt缓存（~3×缓存创建减少）
- **安全修复** — Windows剪贴板CVE修复、托管沙盒权限修复、OTEL隔离
- **macOS性能** — 启动速度提升~60ms，--resume性能提升45%
- **Gateway模型选择器** — /model现在可从gateway的/v1/models端点获取模型列表

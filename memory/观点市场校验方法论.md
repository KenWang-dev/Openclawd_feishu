## 第一层：认知基础（为什么有效）

### 1. 贝叶斯更新 = 成长型思维的数学表达

| 传统思维 | 贝叶斯思维 |
|----------|------------|
| 对 = 成功 | 对 = 概率提升 |
| 错 = 失败 | 错 = 更新数据 |
| 一次性判断 | 持续迭代 |

**本质**：信念不是非黑即白，而是根据新证据不断更新概率。

```
Prior（先验） → 市场反馈 → Posterior（后验）→ 继续抛...
```

---

### 2. 观点 ≠ 事实

| 类型 | 特性 | 处理方式 |
|------|------|----------|
| **事实** | 客观存在，不可否认 | 自己接受 |
| **观点** | 可能对可能错 | 抛出去验证 |

**关键洞察**：只有"观点"才需要校验，"事实"不需要。

---

### 3. 心理安全垫

- **旧模式**：说错 = 被打脸 = 丢脸
- **新模式**：预设"欢迎验证" = 预留纠错空间 = 不触发认知失调

## 第二层：操作方法（怎么做）

### 4. 校验外包流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  抛出观点   │ ──→ │ 市场验证   │ ──→ │  纠正升级   │
│ (分享交流)  │     │ (获取反馈) │     │ (应对预案)  │
└─────────────┘     └─────────────┘     └─────────────┘
       ▲                                       │
       └───────────────────────────────────────┘
              根据反馈再次抛出，继续迭代
```

---

### 5. Gamma 融资法（实操典范）

| 轮次 | 动作 | 结果 |
|------|------|------|
| 第1轮 | 抛想法 | 被质疑ABC |
| 第2轮 | 准备好ABC答案 | 又被质疑DEF |
| 第N轮 | 所有问题都有答案 | 成功 |

**核心**：把"质疑"变成"免费的产品打磨"。

---

### 6. 迭代闭环

```
分享 → 交流 → 验证 → 纠正 → 升级 → 再次分享
```

---

## 第三层：分层决策（判断谁拿主意）

### 7. 决策分层矩阵

| 决策类型 | 例子 | 谁拿主意 | 谁校验 |
|----------|------|----------|--------|
| **生死存亡型** | 核心战略、坚信的方向 | **自己** | 市场反馈供参考 |
| **发展迭代型** | 产品细节、内容输出 | **市场** | 自己微调 |

---

### 8. 核心判断标准

**自己必须拿主意的**：
- 你的核心优势/差异化
- 你坚信但市场暂时不认可的方向
- 生死攸关的决策

**可以外包给市场的**：
- 非核心的细节优化
- 内容/产品的打磨
- 获得市场验证后再推进的方向

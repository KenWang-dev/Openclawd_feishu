### 飞书 Skill 使用方式
1. **读 Skill**: `read ~/.agents/skills/<skill-name>/SKILL.md`
2. **快捷命令**: lark-cli 提供了 `+` 系列 Shortcut
   - `lark-cli docs +fetch --doc <token>` - 获取文档
   - `lark-cli docs +create` - 创建文档
   - `lark-cli docs +search --query "关键词"` - 搜索文档（需 search:docs:read 权限）
   - `lark-cli docs +update` - 更新文档
3. **底层命令**: `lark-cli <资源> <操作> --params '{}'`
   - 例: `lark-cli wiki nodes list --params '{"space_id":"xxx","parent_node_token":""}'`
4. **身份切换**: `--as user`（默认）或 `--as bot`

### 注意事项
- `docs +search` 需要 `search:docs:read` scope，当前用户身份暂未授权此 scope
- Wiki 链接中的 token 不能直接作为 file_token，需要先 `wiki spaces get_node` 查询真实 obj_token
- 大文档建议用 `feishu_doc` 工具（内置）读取，比 lark-cli 返回更完整
- 操作前先读对应的 SKILL.md，里面有完整的参数说明和工作流

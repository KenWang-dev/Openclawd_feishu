## 重要教训

### 🚫 发送文档规则
**绝对不允许发送服务器内部路径/地址给用户。** 用户无法访问服务器，发路径等于无效。
- ❌ 错误做法：`--filePath` 直接用服务器绝对路径（/tmp/xxx.txt），用户收到的是路径文本
- ✅ 正确做法：先把文件上传到飞书云盘（`lark-cli drive +upload`），再通过飞书发送文件消息
- 如果 message tool 的 filePath 不支持飞书文件附件，考虑：
  1. 先 `lark-cli drive +upload` 上传到云盘
  2. 然后用 `lark-cli im +messages-send --file` 发送（需要 user 身份授权）
  3. 或者创建飞书文档分享链接（但这是链接不是文件）
- PDF 发送是成功的案例，说明某种格式/方式是可行的，需要复现那个流程

## 五层知识框架（Ken 认可）

2. 芯片与总线（MCU、UART/SPI/I²C）
3. 模块与外设（传感器、屏幕、无线）
4. 系统架构（选型、BOM、成本）
5. 产品落地（打样、认证、量产）

## MVP 例子：桌面温湿度显示器（¥30）
- 主控 STM32F103 ~¥5、传感器 DHT11/SHT30、0.96" OLED（I²C）
- 传感器→MCU 用 I²C 2线（SDA+SCL），串口思想的活例子
- 屏幕和传感器挂同一条 I²C 总线（一主多从）

## 电子发展史六阶段（Ken 认可的讲法框架）
1. 电（有电1/没电0）
2. 电路（电阻电容二极管三极管，让电干活）
3. 模拟电路（连续信号，会失真）
4. 数字电路（只用0/1，抗干扰）★关键转折
5. 集成电路/芯片 → 两路线：CPU/GPU（性能）| MCU（小省便宜，STM32 属于这类）
6. 芯片间通信：并口（线多）→ 串口（排队逐位传）；I²C/RS-485/USB 都是串行家族

## 核心洞察
1. **上手难度类限制基本过期**：Scrapy 学习曲线、Playwright 配置等，AI agent 几分钟解决；结构清晰的"陡峭"框架反而最适合 AI 改造。
2. **真实限制迁移到**：运行成本（代理池/IP/验证码）、账号风控与合规风险、LLM API 经济性、平台对抗（封堵/改版）——这些 AI 帮不了。
3. **选型口径变化**：一次性任务 vs 例行采集的分界更模糊了，因为工程化框架的 AI 起步成本也降了。

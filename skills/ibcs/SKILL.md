# IBCS 商业沟通标准 Skill

## 核心原则

**IBCS 金律**: 相同含义的内容必须看起来相同，不同含义的内容必须看起来不同。

所有图表、表格、报告、Dashboard 的设计必须遵循 SUCCESS 七法则。详细规则见 `references/ibcs-rules.md`。

## 工作流程

### 1. 接收需求时

当用户要求制作以下任何内容时，自动应用 IBCS 标准：
- 商业报告 / 管理报告 / 财务报告
- 数据分析图表（柱状图、折线图、饼图、瀑布图等）
- 数据表格 / Excel 表格
- PPT / 演示文稿
- Dashboard / 看板
- 任何涉及商业数据展示的内容

### 2. 设计时遵循的三层规则

**第一层：概念层（SAY + STRUCTURE）** — 先想清楚要说什么
- 每页/每图表必须有一个明确的消息（message）
- 标题格式：`[主体] [指标+单位] [时间段]`
- 内容结构：先整体再细节，先过去再未来

**第二层：感知层（EXPRESS + CHECK + CONDENSE + SIMPLIFY）** — 再选对视觉形式
- 优先柱状图/折线图/条形图，避免饼图/仪表盘
- 时间序列放水平轴，结构比较放垂直轴
- Y轴从0开始，不截断
- 不用3D效果、不用花哨渐变
- 黑白灰为基色，颜色留给差异标注

**第三层：语义层（UNIFY — IBCS 记号法）** — 最后统一视觉语言
- 详见下方记号法速查

### 3. IBCS 记号法速查

#### 场景填充模式

| 场景 | 英文 | 填充方式 | 颜色 |
|------|------|---------|------|
| **实际值** | Actual (AC) | **实心填充** | 深蓝/黑色 |
| **过去值** | Previous (PY) | **浅灰实心填充** | 浅灰色 |
| **计划/预算** | Plan/Budget (PL/BU) | **空心轮廓** | 深灰边框 |
| **预测/ forecast** | Forecast (FC) | **斜线填充** | 灰色斜线 |

#### 差异标注

| 差异类型 | 颜色 | 符号 |
|---------|------|------|
| 正向差异（有利） | 🟢 绿色 | ▲ 向上三角 / 加号 |
| 负向差异（不利） | 🔴 红色 | ▼ 向下三角 / 减号 |

> **注意**: "正/负"是指业务含义，不是数值正负。例如成本增加 = 正数值但负差异（不利）。

#### 轴与刻度

- Y轴必须从0开始（比例图除外）
- 同一指标使用相同刻度
- 避免使用网格线，改为在数据点旁直接标注数值
- 避免使用数值轴标签，改为直接在柱/条上标注

#### 高亮标注

- 使用椭圆圈出关键数据点
- 使用趋势箭头表示变化方向
- 使用差异标记（▲▼）标注偏差

### 4. 图表类型选择

| 需求 | 推荐图表 | 避免 |
|------|---------|------|
| 时间序列比较 | 柱状图（水平时间轴） | 折线图（除非>12个时间点） |
| 结构/分类比较 | 条形图（垂直排列） | 饼图 |
| 差异分析 | 瀑布图 | 堆叠柱状图 |
| 占比构成 | 柱状图100% | 饼图、甜甜圈图 |
| 趋势展示 | 折线图 | 面积图 |
| 目标对比 | 柱状图（实心vs空心） | 仪表盘、子弹图 |

### 5. 标题规范

**必含要素**: 主体 + 指标（含单位）+ 时间段

```
✅ 好标题: "华东区 净销售额（百万€） 2024年1月-6月"
❌ 差标题: "销售数据" / "1-6月" / "Dashboard"
```

### 6. 表格规范

- 黑色文字白色背景
- 数字右对齐，文字左对齐
- 不用彩色单元格背景
- 差异列用绿色/红色字体标注
- K/M 单位放在标题中，不放单元格里
- 避免重复的列标题

## 输出检查清单

在交付任何商业图表/报告前，逐项检查：

1. [ ] **SAY**: 每页/每图是否有明确的消息？
2. [ ] **STRUCTURE**: 标题是否包含「主体+指标+时间段」？
3. [ ] **EXPRESS**: 图表类型是否合适？是否避免了饼图/仪表盘？
4. [ ] **SIMPLIFY**: 是否去除了3D效果、多余网格线、外部图例？
5. [ ] **CHECK**: Y轴是否从0开始？刻度是否一致？
6. [ ] **UNIFY**: 场景填充是否符合记号法？（实心=实际、空心=计划、斜线=预测）
7. [ ] **CONDENSE**: 信息密度是否足够高？是否有多余页面可以合并？
8. [ ] 差异标注是否统一（绿=有利、红=不利）？
9. [ ] 时间序列是否在水平轴？
10. [ ] 是否避免在数据区域使用颜色（颜色留给差异）？

# G - 全球采购心声监控

## 基本信息

| 属性 | 周报 |
|------|------|
| 编码 | G2 |
| 阶段 | 发展 |
| 调度 | 周日 14:30 |
| 时间范围 | 过去 7 天 |

## 监控目标

**采购人心声 = 真实的行业图景**，了解同行在关注什么、痛点在哪里。
停掉此监控 = 与行业脉搏脱节 = 决策脱离实际。

## 监控维度（6D × 3 = 18 项指标）

| 维度 | 指标1 | 指标2 | 指标3 |
|------|-------|-------|-------|
| **D1 痛点讨论** | 供应商问题 | 内部流程 | 成本压力 |
| **D2 职业发展** | 技能需求 | 认证趋势 | 薪资水平 |
| **D3 工具讨论** | ERP/系统评价 | 新工具推荐 | 实施经验 |
| **D4 行业话题** | 热门讨论 | 争议话题 | 新概念 |
| **D5 社区动态** | 活动/会议 | 知名KOL | 社区趋势 |
| **D6 情绪分析** | 乐观/悲观 | 焦虑点 | 期待 |

## 分析规则

### 重要性评分

| 分数 | 标准 |
|------|------|
| 5 | 高共鸣痛点、知名观点、行业共识 |
| 4 | 热门讨论、职业趋势 |
| 3 | 一般讨论、经验分享 |
| 2 | 个人吐槽 |
| 1 | 噪音 |

### 情绪分析

| 情绪 | 信号 |
|------|------|
| 😄 乐观 | 机会多、技术红利 |
| 😐 中性 | 正常讨论 |
| 😟 焦虑 | 成本压力、裁员、不确定性 |

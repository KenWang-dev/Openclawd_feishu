# I - 供应商生态系统监控

## 基本信息

| 属性 | 周报 |
|------|------|
| 编码 | I2 |
| 阶段 | 可持续 |
| 调度 | 周日 15:30 |
| 时间范围 | 过去 7 天 |
| 搜索模式 | Tavily Deep |

## 监控目标

**供应商生态 = 采购的战场地形图**，并购和产能变化直接影响供应格局。
停掉此监控 = 对供应格局变化缺乏敏感 = 采购决策滞后。

## 监控维度（5D × 3 = 15 项指标）

| 维度 | 指标1 | 指标2 | 指标3 |
|------|-------|-------|-------|
| **D1 并购重组** | 供应商并购 | 业务剥离 | 合资/联盟 |
| **D2 产能布局** | 新建工厂 | 产能扩张/收缩 | 地域转移 |
| **D3 技术合作** | 技术授权 | 联合研发 | IP交易 |
| **D4 市场进出** | 新进入者 | 退出者 | 破产/重组 |
| **D5 财务健康** | 财报数据 | 评级变化 | 融资动态 |

> 完整分析框架见 `references/supplier-ecosystem-full.md`

## 分析规则

### 重要性评分

| 分数 | 标准 |
|------|------|
| 5 | 头部供应商并购、大额产能投资 |

### 供应格局影响

| 事件类型 | 影响 |
|----------|------|
| 横向并购 | 集中度↑、议价能力变化 |
| 纵向并购 | 产业链整合、竞争变化 |
| 产能扩张 | 供需关系、价格压力 |
| 产能退出 | 供应风险、涨价压力 |

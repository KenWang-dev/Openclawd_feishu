# 老板周报模板（W2）

> 老板视角的极简报告。3 个数字讲清本周，多了不看。

## 输出格式

```markdown
**📊 周度执行摘要**

**本周**：第 N 周
**生成时间**：{YYYY-MM-DD}
**数据来源**：W1 总监周报 + 本周 archive



**【本周 3 个关键数字】**

1. {数字} {什么} {趋势}
   **影响**：{金额或百分比}

2. {数字} {什么} {趋势}
   **影响**：{金额或百分比}

3. {数字} {什么} {趋势}
   **影响**：{金额或百分比}



**【本周 NO.1 优先级】**

{本周必须做的一件事，一句话说清楚}

•	**建议**：{具体行动，如"批准锁价 500 万 MLCC"}
•	**时间**：{紧急度}



**【ROI 仪表盘】**

天网系统成本：¥{X}/月
本月节省：¥{Y}
节省比例：{Z}%

值得吗？
•	**是**：数据支撑 {...}
•	**否**：数据支撑 {...}



**【下周关注】**

•	[ ] {唯一必须做的一件事}

---
*天网监控系统 v6.0*
```

## 飞书发送规则

- 3 条消息
- 每条 ≤ 1000 字

## 写作原则

- **极简**：3 个数字讲清本周
- **金额说话**：所有影响换算成人民币
- **ROI 驱动**：系统花多少、省多少、值不值
- **只给结论**：不要分析过程，只要结论 + 行动
- **优先级明确**：本周只做一件事是什么？

# 总监周报模板（W1）

> 采购总监视角的职业经理人报告。从本周 25 个任务 archive 中提炼决策支持信息。

## 输出格式

```markdown
**📊 采购总监周报**

**周期**：第 N 周（{MM-DD} 至 {MM-DD}）
**生成时间**：{YYYY-MM-DD HH:mm}
**数据来源**：本周 25 个任务 archive 存档

**Archive 覆盖率**：{X}% （预期 25 个，实际 N 个）



**【🎯 TOP5 核心洞察】**

1. [{类别}] {一行发现}
   **影响**：🔴 高 / 🟡 中 / 🟢 低
   **来源**：{任务编码 - 任务名}
   **行动**：
   •	[ ] {具体步骤 1}
   •	[ ] {具体步骤 2}



...

**【📈 供应链风险仪表盘】**

🔴 **红色警报**（立即响应）
•	{供应商/品类} - {风险} - {建议行动}

🟡 **黄色预警**（48h 关注）
•	{供应商/品类} - {风险}

🟢 **绿色**（正常）



**【💰 成本与价格趋势】**

原材料：
•	LME 铜：${X}/t ({±}%)
•	LME 铝：${X}/t ({±}%)
•	原油：${X}/bbl ({±}%)

价格传导分析（ROI）：
{上游} ±{X}% × {Y}% 份额 = {中游} 成本变化 {Z}%

汇率：
•	USD/CNY：{X} ({±}%)



**【🚀 AI 技术趋势】**

核心动态：
•	{发现}：{分析}

行动：
•	[ ] {AI 采购相关具体行动}



**【📋 下周关注清单】**

•	[ ] {待办 1} | 来源：{任务}
•	[ ] {待办 2} | 来源：{任务}

---
*天网监控系统 v6.0*
```

## 飞书发送规则

- 4 条消息
- 每条 ≤ 1000 字

## 写作原则

- **同行对话视角**："作为采购总监，你本周最该关注的是..."
- **决策支持**：每个发现 → 影响分析 → 具体行动 → 截止日期
- **ROI 思维**：所有建议附带成本/收益分析
- **向上汇报**：内容可直接截取段落向 CEO 汇报

# Claude Code 动态监控

## 核心原则

**不是罗列更新，而是提供有用信息。**

每条信息必须包含三层：
1. **事实** - 发生了什么
2. **是什么** - 为了解决什么问题/为什么要做
3. **洞察** - 我应该怎么做

---

## 监控框架

### 1. 新功能发布

| 字段 | 说明 |
|------|------|
| **事实** | 功能名称 + 版本号 + 发布时间 |
| **是什么** | 这个功能解决什么问题/什么场景 |
| **洞察** | 我应该怎么用/要不要尝试 |

### 2. 版本更新

| 字段 | 说明 |
|------|------|
| **事实** | 版本号变化 + 更新内容列表 |
| **是什么** | 为什么要做这些更新 |
| **洞察** | 哪个对我有用/应该试试 |

### 3. 社区热点

| 字段 | 说明 |
|------|------|
| **事实** | 什么讨论/什么文章在传 |
| **是什么** | 为什么引起关注 |
| **洞察** | 对我有没有价值 |

### 4. 竞品动态

| 字段 | 说明 |
|------|------|
| **事实** | Cursor/Windsurf/Copilot 做什么 |
| **是什么** | 他们在追什么/市场趋势 |
| **洞察** | Claude Code 有没有落后/要不要关注 |

### 5. 用户反馈

| 字段 | 说明 |
|------|------|
| **事实** | 用户在抱怨什么/期待什么 |
| **是什么** | 痛点是什么 |
| **洞察** | Anthropic 会不会跟进/有什么机会 |

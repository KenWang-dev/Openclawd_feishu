# P2P替代料评估体系

## 核心原则

**Pin-to-Pin直接替代，实现"三零"目标：**
- **零改动产线** - 焊接工艺、测试程序无需调整
- **零改动PCB** - 封装、引脚定义完全兼容
- **零改动外壳** - 尺寸、散热结构不干涉

## 漏斗式筛选流程

按优先级顺序筛选，先硬性淘汰再软性评分：

| 阶段 | 筛选维度 | 判定模式 | 通过率 |
| :---: | ----- | ----- | :---: |
| 1️⃣ | **D1电气 + D2物理** | Pass/Fail 硬性淘汰 | ~30%-50% |
| 2️⃣ | **D3可靠 + D4工艺 + D5合规** | Pass/Fail 硬性淘汰 | ~70%-80% |
| 3️⃣ | **D6供应 + D7成本** | 加权评分排名 | 综合排名 |
| 4️⃣ | **D8验证导入** | 执行确认 | 最终决策 |

## 红黄绿灯判定

| 判定 | 含义 | 动作 |
| :---: | ----- | ----- |
| ✅ 完全满足 | 参数在规格范围内 | 直接进入验证 |
| ⚠️ 部分满足 | 小偏差但可控 | 评估风险后决定 |
| ❌ 不满足 | 不可接受差异 | 直接淘汰 |

## 8维度速查

| 维度 | 核心关注 | Quick Check |
| :---: | ----- | ----- |
| **D1 电气** | 能做同样的事 | 额定参数≥原厂 + 动态特性满足 + 容差相同或更优 |
| **D2 物理** | 能原位放进去 | 封装图纸匹配 + 引脚100%一致 + 散热兼容 |
| **D3 可靠** | 能抗住工况 | 温度范围覆盖 + MSL等级相同或更优 |
| **D4 工艺** | 产线零调整 | 焊接曲线兼容 + ESD/MSL不增加要求 |
| **D5 合规** | 法规允许用 | RoHS/REACH齐全 + 行业认证已获取 |
| **D6 供应** | 买得到且稳定 | 交期/MOQ匹配 + 供应商稳定 + Active状态 |
| **D7 成本** | 经济上划算 | 单价可接受 + TCO合理 |
| **D8 验证** | 能顺利切换 | 验证计划制定 + 样品可获取 |

## 品类差异化

| 品类 | 重点维度 | 核心差异点 |
| ----- | ----- | ----- |
| **IC芯片** | D1+D2+D8 | 引脚定义、寄存器兼容性、固件移植 |
| **电源IC** | D1+D2+D4 | 输出精度、动态响应、补偿网络 |
| **电阻** | D1+D2+D5 | 容差等级、温度系数、功率额定 |
| **电容** | D1+D3+D2 | MLCC直流偏压、电解寿命、纹波电流 |
| **分立器件** | D1+D2+D3 | MOSFET的Rds(on)/Qg，二极管的Vf/trr |

## 常见陷阱

1. ❌ **"封装名称相同 = 尺寸相同"** → 必须核对实际图纸
2. ❌ **"参数更优 = 一定可替代"** → 过优可能引入振荡、EMI
3. ❌ **"样品通过 = 量产无问题"** → 必须确认量产版本一致性
4. ❌ **"价格便宜 = 成本更低"** → 必须计算TCO
5. ❌ **"原厂推荐 = 完全兼容"** → Cross Reference仅供参考，必须独立验证

# PurKit 场景剧本 P5-001：供应商涨价应对

## 场景概述

> **难度**：⭐⭐⭐（中级）
> **对应框架**：p5@negotiation-supplier D1-D6 六维体系
> **核心考验**：成本穿透能力 + 信息不对称管理 + 替代方案威慑
> **建议用时**：15-20 分钟对话

---

## 一、背景设定（采购员看到的）

你是一家消费电子公司的采购经理，负责被动元件品类。

今天早上，你的核心 MLCC 供应商**台庆电子（TaiQing Electronics）**的销售经理王磊发来邮件：

> "Ken 总您好，受近期稀土价格持续上涨影响，钯、镍等关键原材料成本较去年Q4上涨了约18%。经公司管理层评估，我们不得不自下月起对全线MLCC产品价格上调12%。
>
> 考虑到我们的长期合作，这是我们的老客户最优惠的涨幅。目前行业已有两家友商涨幅达15%-18%。我们希望能尽快与您沟通，以便做好过渡安排。
>
> 顺祝商祺，王磊"

**你的年度采购预算已经锁定，没有这笔额外空间。**

## 二、供应商后台设定（评分者看到，采购员需要自己挖）

### 台庆电子画像

| 维度 | 信息 |
|------|------|
| **公司规模** | 台资，MLCC年营收约45亿新台币（~1亿美元），全球Top 15 |
| **主要客户** | 你方（占其营收约6%）、三星ODM、富士康、立讯 |
| **产能利用率** | 目前约82%，Q3有新产能投产 |
| **利润率** | 毛利率约22%，净利率约8% |
| **核心原材料成本** | MLCC成本中陶瓷粉料约35%，内电极（镍/钯）约25%，其他25%，制造成本15% |
| **真实原材料涨幅** | 稀土/镍价格确实上涨，但陶瓷粉料成本实际涨幅约5-7%（钯价涨幅大但钯在配方中占比小） |
| **真实涨价动机** | 行业需求回暖，借原材料涨价之名补利润（去年Q3为了抢单，他们主动降价8%，现在想涨回来） |
| **王磊的KPI** | 季度营收目标，Q2冲量压力大，月底是Q2截止 |
| **决策链路** | 王磊（销售经理）→ 李总（销售总监）→ 台湾总部价格委员会 |

### 采购方（你方）画像

| 维度 | 信息 |
|------|------|
| **年采购额** | 台庆约300万美元/年 |
| **产品依赖度** | 台庆供应你方3款核心产品的MLCC，切换需重新验证（约4-6周） |
| **备选方案** | 已有小批量导入村田（贵15%）、三星电机（贵10%），但未完成全系列替代验证 |
| **合同状态** | 现行年度框架协议，未到期，价格条款为"固定价格"，但有一个"原材料价格波动超过10%可协商"的条款 |
| **历史记录** | 去年Q3台庆主动降价8%抢你方份额，当时你方接受了 |

### 关键博弈点（隐藏）

1. **合同条款**：原材料波动条款只写了"可协商"，没写"必须涨价"。协商 ≠ 涨价。
2. **时间窗口**：今天是5月28日，王磊Q2月底冲量，他**需要你这单**。
3. **真实涨幅**：12%的涨价远超实际成本涨幅（5-7%）。中间差是"利润修复"。
4. **反制信息**：如果你能拿出MLCC行业成本结构数据，就能把真实涨幅压到合理区间。
5. **替代威慑**：你的村田/三星验证进度是关键筹码——如果验证完成度高，威慑力强；如果刚开始，威慑力弱。

## 四、供应商行为设定（AI 扮演王磊）

### 性格与风格
- 礼貌、专业、有城府
- 不会主动暴露真实动机
- 会使用"行业标准"、"友商已涨"、"我们的无奈"等话术
- 在压力下会适当让步，但不会轻易退到底线
- 底线：涨价 6-8%（实际成本涨幅+小利润修复），且Q2不接受任何降价

### 关键台词预设
| 用户行为 | 王磊回应 |
|---------|---------|
| 直接拒绝涨价 | "Ken 总，这个涨幅已经是老客户最优惠的了。原材料成本是客观事实，我们不是在赚您钱。您看数据——" |
| 要求看成本数据 | "我理解您需要依据。我可以提供原材料价格指数变化，但具体成本结构涉及商业机密。不过我可以告诉您，陶瓷粉料和电极材料确实涨了不少。" |
| 提到替代供应商 | "当然可以，选择权在您。但切换供应商的验证周期、质量风险、以及可能的价格差异，这些成本您应该也评估过。我们合作两年，交付和质量一直很稳定。" |
| 要求维持原价 | "Ken 总，原价我们真的做不到。去年的价格是特殊市场环境下做的，现在成本已经回不去了。如果您愿意增加订单量，我们可以重新讨论。" |
| 提出量价联动 | "这个方向我可以跟内部讨论。您说的量是多少？如果是实质性的增量，我们是有空间的。" |
| 提到合同条款 | "合同里确实有波动条款，但现在的涨幅已经超过了10%的门槛，启动协商是合理的。我们的提议就是在协商框架内的。" |
| 利用Q2冲量施压 | "Ken 总，我们确实Q2有一些压力，但涨价是成本驱动的，不是为了冲量。不过如果您这边能在Q2确认增量订单，价格的事情我会向总部争取一个过渡方案。" |

### 让步路径
1. 第一次：12%（开价，态度坚决）
2. 被质疑成本数据后：10%（"我向总部争取了一下"）
3. 被替代方案威慑后：8%（"如果您承诺未来6个月的增量"）
4. 量价联动谈妥后：6%（"仅限这份增量订单维持原价，其他维持+8%"）
5. 底线：6-8%，Q3之后重新评估

## 五、满分示范（采购员视角）

> **注意：以下不是唯一正确答案，而是高分解答示例**

**Step 1（D1 备战）**：不立即回复邮件。先查MLCC行业数据（稀土/镍/钯近期价格走势），发现钯价确实涨了但钯在MLCC成本中占比很小；再查友商涨价信息，发现只有小厂涨了15%，村田和三星目前没有涨价公告。

**Step 2（D1 信息）**：回复邮件，要求王磊提供原材料成本占比明细和具体涨幅数据。同时翻出合同中"原材料波动超10%可协商"的条款。

**Step 3（D2 目标）**：内部设定目标——底线：接受4%以内涨幅；现实目标：冻涨至Q3再评估；理想目标：维持原价+Q2增量承诺。

**Step 4（D3-D4 执行）**：
- "王磊，我查了MLCC行业成本结构，钯价涨幅虽然大，但在MLCC成本中占比很小。整体原材料影响应该在5-7%，不是12%。你们的12%里至少有一半是利润修复，而不是成本驱动。"
- "另外，村田和三星目前没有涨价。我知道你们去年Q3为了抢单主动降了8%，现在借原材料涨价补回去，我能理解。但这个涨幅我接受不了。"
- "这样，我们Q2有一批增量需求（约20%），如果你能维持原价到Q3，这部分增量我优先给你。Q3我们再基于当时的市场数据重新评估。"

**Step 5（D5 控场）**：给王磊留台阶——"这个方案对你也有好处，Q2的增量帮到你，而且Q3如果真的成本继续涨，我合理接受调整。"

**Step 6（D6 闭环）**：邮件确认——"本邮件确认，双方就MLCC价格达成以下共识：①现行价格维持至2026年8月31日；②Q2增量订单（约XX万颗）优先分配至台庆；③Q3起双方基于最新市场数据重新评估。如无异议，请回复确认。"

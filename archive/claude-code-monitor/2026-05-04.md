📦 版本更新

【v2.1.126 — 大版本更新】
- 事实：Claude Code 5月初发布 v2.1.126，涵盖智能模型选择、项目清理工具、权限处理强化、OAuth 登录改善、Windows/PowerShell 修复、遥测优化等 30+ 项改进
- 是什么：解决企业级部署中的几个核心痛点——自定义网关模型发现、项目级状态清理、OAuth 在容器/WSL2 等环境的兼容性
- 洞察：
  - `claude project purge` 是重磅工具，长期使用 Claude Code 后积累的 transcripts/tasks/config 终于可以一键清理
  - `--dangerously-skip-permissions` 扩展到 .claude/.git/.vscode/ 等路径——适合 CI/CD 场景，但生产环境慎用
  - `/model` 现在能发现自定义网关的模型列表，对使用 Bedrock/Vertex/自建网关的用户是重大改善
  - Windows 用户终于被认真对待：PowerShell 7 自动检测 + 作为默认 Shell

【v2.1.122 — Bedrock 服务层级选择】
- 事实：新增 `ANTHROPIC_BEDROCK_SERVICE_TIER` 环境变量（default/flex/priority）；`/resume` 支持粘贴 PR URL 直接定位会话；OpenTelemetry 日志扩展
- 是什么：让 Bedrock 用户能精细控制成本与延迟的平衡；PR URL 回溯让多分支工作流更顺畅
- 洞察：Bedrock 用户强烈建议设置此变量，flex tier 可以显著降低成本

【v2.1.123 — OAuth 修复】
- 事实：修复了 `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` 导致的 OAuth 401 循环
- 是什么：企业合规环境常见配置导致认证失败，快速修复
- 洞察：如果你设置了此环境变量且遇到登录问题，升级即可

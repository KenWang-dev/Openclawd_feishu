🦊 Claude Code 动态监控 - 2026年11月20日

📦 新功能/版本更新

【Code Mode（实验性）】
- 事实：v2.1.319 引入 Code Mode，Claude 通过编写 JavaScript 来调用工具；v2.1.326 扩展至支持 agent teams
- 是什么：让 Claude 用代码而非自然语言来编排工具调用，减少歧义、提高执行可靠性
- 洞察：对于复杂多步工作流可能显著提升准确性，可在 `/config` 中开启实验

【MCP 后台任务】
- 事实：v2.1.319 新增 MCP tasks 移至后台执行
- 是什么：长时间运行的 MCP 工具调用不再阻塞主会话
- 洞察：适合需要异步执行的场景（如长时构建、数据处理），提升并行能力

【plugin.json 版本引擎】
- 事实：新增 `engines["claude-code"]` 字段，插件可声明兼容版本范围
- 是什么：不兼容的插件不会被安装/加载/更新，避免版本冲突导致崩溃
- 洞察：对插件生态成熟度有里程碑意义，建议插件作者尽快加上

【permissions.denyInsteadOfPrompting】
- 事实：v2.1.319 新增权限配置项，可直接拒绝而非弹窗询问
- 是什么：CI/CD 或无人值守场景下避免卡在权限提示
- 洞察：自动化部署场景必备

【安全：zstd 解码修复】
- 事实：v2.1.325 修复 zstd 压缩响应解码中的安全问题
- 是什么：防止恶意压缩响应导致的问题
- 洞察：建议尽快升级到 ≥2.1.325

【Bash 沙箱权限强化】
- 事实：v2.1.326 收紧 `cp`/`mv` 及敏感目录写入的权限检查
- 是什么：防止 agent 意外修改 home 目录等敏感路径
- 洞察：可能影响现有脚本，升级后需验证权限规则

🌐 社区热点

【Claude Code 使用率登顶】
- 事实：Stack Overflow 2026 调查显示 Claude Code 以 65.5% 使用率领跑 AI 编码工具，GitHub Copilot 58.7%，Codex CLI 29.5%
- 是什么：CLI-first 模式 + Opus 4.7 SWE-bench 87.6% 的组合正在胜出
- 洞察：生态和社区惯性已形成，第三方插件/教程资源将加速增长

【Anthropic 使用政策更新（11/12）】
- 事实：11月12日起更新使用政策，明确禁止滥用行为
- 是什么：针对自动化刷量/滥用 API 的行为加强管控
- 洞察：正常使用不受影响，但需注意批量自动化场景的合规边界

🔧 竞品动态

【Cursor — $9B 估值 Series B】
- 事实：Cursor 完成 B 轮融资估值 $90 亿，Composer agent 被评为 2026 最佳跨文件编辑 AI
- 是什么：IDE 路线 vs Claude Code 的 CLI 路线，两条路线并存
- 洞察：Cursor 在 IDE 体验上领先，Claude Code 在自动化/可编程性上领先，互补大于竞争

【Windsurf 被 OpenAI 收编】

- 洞察：竞争格局清晰化——Anthropic（CLI）vs OpenAI（IDE）vs GitHub（Copilot 内嵌）

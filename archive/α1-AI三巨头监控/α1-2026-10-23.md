## 🔥 Top 5 核心情报

1. **OpenAI Decisions API 正式发布（GA）— 新品类 API**
   - 时间：10月22日 | 重要性：5/5
   - 基于 GPT-6 Luna 构建，专注"有界答案"决策任务：概率/选项/评分三类输出，速度比经 Responses API 调用 Luna 快 10 倍
   - 已加入 GPT-Live 原生集成、prompt caching、美欧推理数据驻留；单请求支持最多 400 个问题（翻倍），并扩充亚洲区域容量
   - 定位：Agent 工作流中海量小决策的低成本/低延迟基础设施

2. **Uber 向全部 3 万+ 员工推送 ChatGPT Work**
   - 时间：10月22日 | 重要性：4/5
   - 企业级 AI 办公从试点走向全员部署，覆盖研究、数据分析、演示制作、复杂工作流；AT&T 同步披露法务场景落地案例
   - 信号：企业 AI 采购进入"全员 seat"阶段，ChatGPT Work 与 Microsoft/Google 办公套件正面竞争

3. **Anthropic 发布 Claude Duet 研究预览（Pro/Max 用户）**
   - 时间：10月21日 | 重要性：4/5
   - 全新 App 形态，Claude 作为"主动式 Agent"（proactive agent）工作，而非被动应答
   - 与 OpenAI 的代理化路线（Codex/Decisions）对标，Anthropic 从模型公司向 Agent 产品公司转型加速

4. **Google Gemini 4 Argon 全球可用，登顶 Vals Index**
   - 时间：10月13日发布，本周持续扩散 | 重要性：4/5
   - 旗舰前沿模型：编码/金融/法律/网络安全/科学多领域登顶 Vals Index（跨经济部门基准）
   - 定价 $2/M 输入、$10/M 输出，缓存输入 95% 折扣——旗舰级激进定价，直接对打 GPT-6 与 Claude Opus 5.5

5. **Anthropic 设立 Public Benefit Fund（公共利益基金）**
   - 时间：10月18日 | 重要性：3/5
   - 承诺将公司股份的一部分注入新实体 Anthropic Public Benefit Fund，随公司成长提高占比
   - 治理结构创新，IPO 前强化"安全优先"叙事，可能与上市准备相关
